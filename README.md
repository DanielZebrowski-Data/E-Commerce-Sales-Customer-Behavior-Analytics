#🛒 E-Commerce Sales & Customer Analytics
##📌 Project Overview

This project focuses on analyzing e-commerce sales and customer data using PostgreSQL.

The main goal was to build a structured analytical database, validate the quality of transactional data, and prepare SQL-based datasets for further business analysis and BI reporting.
The project covers the full analytical workflow:
Raw Data → Data Modeling → Data Quality Checks → SQL Analysis → Analytical Views

Rather than focusing only on writing SQL queries, the project emphasizes understanding the structure, quality, and business meaning of the data before using it for analysis.

--- 

##🎯 Business Questions

The analysis is designed to answer questions such as:

- **How much revenue is generated from sales?
- **How many orders and units are sold?
- **What is the average order value (AOV)?
- **Which customer markets generate the most sales?
- **How do order statuses and payment methods differ?
- **How is customer activity distributed across different markets?
- **Are the financial calculations in the source data consistent?
